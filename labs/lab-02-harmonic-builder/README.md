# Lab 02 — Harmonic builder

Build a square wave from sines and watch the spectrum update live.

## Docs writeup

- Site: `/#/labs/lab-02-harmonic-builder-overview`

## Quick start

```bash
mod ad101
cd labs/lab-02-harmonic-builder
python3 src/explore.py
python3 src/explore.py --headless
```
